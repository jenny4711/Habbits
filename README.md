## 📱 About the App

**Habbits** is an iOS app designed to help you build and track personal habits. With an intuitive interface and powerful features, it assists you in achieving your goals.

### ✨ Key Features

- 🎨 **Customization**: Express your habits with emojis and colors
- 📊 **Progress Tracking**: Daily check-ins and streak counting
- 🔔 **Notification System**: Push notifications to remind you of your habits
- 📈 **Statistics**: Detailed statistics and progress visualization
- 🌙 **Dark Mode**: Eye-friendly dark theme support
- 💾 **Local Storage**: Secure data storage on your device



### Prerequisites

- iOS 15.0 or later
- Xcode 14.0 or later
- Swift 5.7 or later



## 🛠️ Tech Stack

- **Language**: Swift 5.7+
- **UI Framework**: SwiftUI
- **Architecture**: MVVM (Model-View-ViewModel)
- **Data Storage**: UserDefaults + Codable
- **Notifications**: UserNotifications
- **Dependency Management**: CocoaPods

## 🎯 How to Use

### 1. Adding Habits
- Tap the ➕ button to add a new habit
- Choose emoji and color to personalize your habit
- Set notification time to get daily reminders

### 2. Daily Check-ins
- Tap the check button when you complete your habit
- Streak count is automatically calculated

### 3. View Statistics
- Check your progress in each habit's detail page
- View streak count and overall completion rate
